# Setu / SpiderNet project law

Setu is the bridge deck.

Rules:
- Preserve the white Setu UI unless explicitly approved otherwise.
- Do not touch unrelated files.
- Separate inferred from verified.
- Never claim verified unless checks actually pass.
- Keep logs useful and product-relevant.
- Freeze, mirror, recovery, Brain, FTD, and architecture maps matter.
- Do not delete anything unless explicitly approved.
- Always ask before destructive or irreversible actions.
- Resume from the last verified repo state, not from scratch.
- State the last verified milestone, touched files, and smallest justified next step before major edits.
- Reject duplicate active runs for the same Setu path.

Working style:
- Review repo state first.
- Read logs, plans/ftd.md, rul/, docs/architecture/, and recent diffs.
- Prefer minimal, typed, safe changes.
- Suggest better ideas, but do not silently expand scope.
